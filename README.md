# Music Notebook · 知识白板与四小节鼓模块

## 更新到原 GitHub 网站

1. 在旧网站点击「导出备份」，保存当前笔记和本地素材。
2. 解压，上传以下 8 个程序文件到原仓库根目录，覆盖同名文件：
   - index.html
   - style.css
   - app.js
   - midi.js
   - modules.js
   - drums.js
   - whiteboard.js（新增，必须上传）
   - boot.js
3. 保留原来的 content.json 和 assets/。本包没有 content.json，不会用示例覆盖笔记。
4. Commit changes 后等待 Pages 部署完成，在原网址刷新。
5. 程序链接带新版缓存参数。若仍显示旧界面，Windows 按 Ctrl+F5，Mac 按 Cmd+Shift+R。

content.example.json 仅用于新建仓库：首次搭建时可以将它改名为 content.json；旧仓库不要这样做。

代码都经过规范缩进和换行，关键模块有中文注释。网站不依赖 npm 或构建工具。

## 鼓模块：浏览页面

- 控制栏仅保留「播放、BPM、拍号」。
- 不显示鼓部件管理、总小节、Swing、手型、起点、循环开关或前后八小节等旧控件。
- 每次显示四小节，后续内容使用下方真正的水平滚动条浏览，部件名称保持固定。
- 鼠标点击部件文字即可静音 / 取消静音；静音轨名称会淡化并划线，右侧显示 M。
- 鼓点不跟随播放逐格高亮，仍使用连续移动的一根竖线。
- 鼠标在最上方小节方块区域按住拖动，松手选中整小节范围。选中范围用浅绿底色标示，只在这些小节内循环。
- 没有选择时循环整个节奏。再次框选同一个范围，或让鼓网格获得焦点后按 Esc，取消选中。
- 单击一个小节方块可选中单个小节。选中停止当前播放，点击播放后从选中范围起点开始。
- 可以先拖动滚动条显示后续四小节，再框选它们。按住小节框选时改变滚动条位置，可选择跨视窗范围。
- 播放进入视窗外的内容时会自动滚动显示下一组四小节。

## 鼓模块：编辑页面

- 比浏览页面多一个「管理鼓部件」按钮。
- 管理弹窗只有「显示」勾选项，没有静音勾选项。静音同样通过点击部件名称操作。
- 勾选几个部件就显示几行；取消显示保留原鼓点，同时不让隐藏轨发声。
- 保留 21 种部件 / 打法，包括底鼓标准、轻击、深低频、短促重击；军鼓标准、幽灵音、Rimshot、刷奏、边击、Cross-stick；踩镲、通鼓、吊镲与叮叮镲等。
- 点空白添加鼓点，点已有鼓点删除，左右拖动已有鼓点改变时间位置。
- 目标已有鼓点时拒绝覆盖，以保留原鼓点。
- 编辑时滚动条末尾会留出四个空白小节，点击空白小节的格子会自动延长节奏，不需要额外的总小节控件。
- 音色仍是浏览器合成试听，并非专业鼓采样。

## 知识块白板

- 编辑页顶部只新增「知识块」，不再直接创建零散顶层内容，也没有「细分模块」按钮。
- 知识块固定保留大标题。可通过「＋ 标题」添加 2–6 级标题，编辑时能更改文字与级别，也能删除这些可选标题。
- 「＋ 内容块」菜单固定为：文本、鼓、音符块、图片、音频。
- 每个内容块都可以通过左上角 ⠿ 拖动条移动到白板任意位置；右下角 ◢ 可调整尺寸。
- 标题区固定在白板上方，内容区为自由布局，允许内容块交错或重叠。拖动与调整尺寸后的坐标会保存。
- 白板较宽或较高时，用白板自身的水平 / 垂直滚动条浏览。小屏设备不会擅自把自由排布转换成列表。
- 内容块的编辑、鼓点手势、音符手势与白板拖动各使用自己的区域，避免误操作。
- 键盘焦点在拖动条或缩放角时，方向键也能移动或调整尺寸；Shift + 方向键扩大步长。
- 知识块仍可添加标签、练习标签、练习分类、待复习标记；知识与练习目录继续使用上一版逻辑。
- 知识块操作菜单保留上移 / 下移、复制、删除；内容块菜单有练习标签、复制与删除。

## 图片与音频拖拽上传

- 可直接把图片或音频拖到白板空白处，自动创建相应内容块，放在落点位置。
- 也可先创建图片 / 音频内容块，再将文件拖入该块的上传区，或点击选择文件。
- 图片支持 PNG/JPG/GIF/WebP，单个最大 10 MB；音频单个最大 50 MB，建议 MP3/WAV。
- 上传先写入本机 IndexedDB，再保存笔记引用。当前浏览器刷新后仍能恢复。
- 支持一次拖入多个图片 / 音频，每个文件形成独立内容块。
- 导出完整备份会包含本机素材；GitHub 同步会沿用之前的素材上传功能。授权令牌只保留在网页内存。

## 旧笔记兼容

- 旧版顶层文字、鼓、MIDI 和素材会放进知识白板，原内容块 ID 保留，因此练习引用仍指向原内容。
- 原有 group 容器会作为知识块显示；旧细分容器及其内部内容保留可读，不再提供创建细分容器的按钮。
- 原有音符、鼓点、标签、练习分类与媒体引用不删除。
- 首次迁移给内容块安排默认位置和大小，之后可以自由调整。
- 仍使用 version:1 数据结构，新增 board、headings、layout 等可选字段。

## 文件分工

| 文件                   | 职责                                            |
| ---------------------- | ----------------------------------------------- |
| app.js                 | 基础页面、数据、保存与同步                      |
| modules.js             | 知识 / 练习目录、媒体存储、统一播放             |
| midi.js                | 原有音符编辑、MIDI 导入 / 导出及示例            |
| drums.js               | 四小节鼓网格、名称静音、框选循环与部件选择      |
| whiteboard.js          | 知识白板、标题、内容块拖动 / 缩放、文件落点上传 |
| boot.js                | 恢复数据并启动页面                              |
| index.html / style.css | 网页结构与样式                                  |

加载顺序：midi.js → app.js → modules.js → drums.js → whiteboard.js → boot.js。
